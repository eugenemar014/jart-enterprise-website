# JART Enterprise Website

Responsive website for JART Enterprise, a frozen meat importer and commercial supplier established in 2018.

## Project structure

- `index.html` - Main website
- `style.css` - Website design and responsive layout
- `script.js` - Mobile menu, year, and inquiry form
- Product and hero photography is currently loaded from Unsplash.

## How to run in Visual Studio

### Option 1 - Visual Studio Code
1. Extract the ZIP file.
2. Open the `JART_Enterprise_Website` folder in Visual Studio Code.
3. Open `index.html`.
4. Install the "Live Server" extension if you want automatic browser refresh.
5. Right-click `index.html` and choose "Open with Live Server".

### Option 2 - Visual Studio
1. Extract the ZIP.
2. Open Visual Studio.
3. Choose **Open a local folder**.
4. Select the `JART_Enterprise_Website` folder.
5. Open `index.html` in your browser.

## Contact form

The inquiry form opens the visitor's email application with a prefilled message addressed to `jartenterprise@yahoo.com`. It does not send data to a server.

## Publish with GitHub Pages

The site is static and can be served directly from the repository root. In GitHub, open **Settings → Pages**, select the `main` branch and `/ (root)` as the build source, then save. GitHub Pages will provide the public URL after its first deployment.
